# Game Club Partnership Site

This folder contains the redesigned two-level talent-agent website.

- `index.html` is the agent-focused intro page.
- `details.html` is the deeper details page with the interactive economics calculator.
- `styles.css` and `app.js` are shared by both pages.
- `game-club-hero.png` is the abstract hero asset used on the intro page.
- `logos/` contains the Influence Mobile and publisher logo assets used in the site.

Open `index.html` in a browser to review the site.
